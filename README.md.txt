# SQL Book Ordered Project

## Project Overview

This project demonstrates how to use PostgreSQL to create a database, import data from CSV files, and perform SQL queries for data analysis on a book ordering dataset.

## Tools Used

* PostgreSQL
* pgAdmin 4
* Microsoft Excel
* GitHub

## Dataset

The project uses the following datasets:

* Books.csv
* Customers.csv
* Orders.csv

## Project Structure

## SQL Concepts Used

* CREATE TABLE
* SELECT
* WHERE
* ORDER BY
* GROUP BY
* HAVING
* Aggregate Functions
* INNER JOIN
* LEFT JOIN
* RIGHT JOIN
* Subqueries

## How to Run

1. Create a PostgreSQL database.
2. Execute `SQL_Table_Created.sql` to create the tables.
3. Import the CSV files from the `datasets` folder.
4. Run `Basic_Queries_Solved.sql`.
5. Run `Advance_Queries_Solved.sql`.

## Learning Outcomes

Through this project, I practiced:

* Creating relational database tables
